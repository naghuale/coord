# Авторство и история

Владелец проекта и автор исходных требований: пользователь этой рабочей сессии.
Git identity на момент первого локального commit: `naghuale <naghuale@gmail.com>`.

Реализация, тесты, примеры и документация подготовлены с помощью OpenAI Codex
по требованиям владельца. Этот факт отражён в теле начального commit; Codex
не представлен как отдельный человек и не использует вымышленный email.

Git фиксирует автора, коммитера, дату, сообщение и изменения каждого commit.
Имя в Git — настроенная identity, а не криптографическое подтверждение личности.

```sh
git log --format=fuller
git log --stat
git show HEAD
git blame coordinator.go
git log --follow -- docs/ROADMAP.md
```

Будущие участники используют собственные `user.name` и `user.email`.
Менять identity другого участника или переписывать его авторство нельзя.
